# M3 文本剪贴板与故障恢复

更新：2026-10-30。M3 文本同步与 M3.1 消息身份修复已整合到正式 v1.4.9，诊断 `m3.1`。本文说明已实现的范围和仍需真机验收的边界。

## 本轮实现

- 两端独立开关，默认关闭；只在设备证书已配对、流转启用且输入连接就绪时读写文本剪贴板。普通桌面应用执行剪贴板 IO，Windows SYSTEM 输入服务不接触文本。
- UTF-8 文本最大 1 MiB。已认证对端可使用有界大消息帧；首次接触/配对保留 32 KiB 限制。内容只驻留内存，不进入房间、日志或诊断；上游输入核心的全格式剪贴板仍关闭。
- 连接期新复制才触发同步。会话使用独立随机标识，断开/停用/撤权会清空待同步状态；旧会话回复不能复活内容，发送方在每个 TLS 分块前重新检查会话，关闭开关后停止后续分块。Lamport 版本和设备 ID 为同时复制提供确定性排序，写入回读不产生回环。
- 新增“收回并停止输入”，停止本机输入进程并保留配对，重新开启后才能连接；Mac 路径不等待网络或核心 IPC 回复。
- Mac 另设独立线程监测自有核心的私有 IPC，曾成功响应后连续两次超时会终止当前自有子进程、暂停流转并显示原因；睡眠造成监测间隔变长后重新建立健康基线，避免把唤醒暂缓当成挂死。
- 修饰键配置按对端 ID 分别保存，兼容已有全局默认配置。

## 必须保留的验收边界

1. 1 MiB 的协议与双向逻辑测试不替代两台真实电脑的系统剪贴板时延验收。需测试双向中文/多行文本、1 MiB、超限、同时复制、开关和断网。
2. Mac 独立监测覆盖私有 IPC 无响应，不能推断所有输入线程故障均可检测。Windows 服务已有会话锁定/应用退出/进程生命周期管理，尚未完成目标输入进程挂死时的独立逐键释放。
3. 端到端主动释放 100 ms、断网 2 s、物理键鼠拔除后的按键/鼠标按钮状态，以及休眠/多网卡恢复指标仍待故障注入和真机确认。当前配置启用 500 ms 上游心跳，但配置值不等于实际达标。
4. 严格按房间成员过滤候选、RTT/丢包/会话时长、全局热键自定义、多显示器精细布局、双方实体键鼠本地接管，以及 8 MB 包体目标继续保留为未完成项目。

## 双机测试

两端更新 [v1.4.9 正式安装包](https://github.com/WendelYu/WenBox/releases/tag/v1.4.9)，保持原配对；开启流转并确认能跨屏输入。分别开启文本同步，等待就绪，再复制中文多行命令到对端记事本粘贴；交换方向。复制 1 MiB 文本核对字节内容，复制超过 1 MiB 确认提示。

关闭任一端开关、停止流转、解除配对或断网后复制文本，不应写入对端。恢复后不应补发断开期间的旧内容，新复制后才同步。复制图片不应传输图片数据。

在普通桌面与 UAC 操作期间测试返回主控热键；出现无法恢复时保留实体输入兜底。应用“收回并停止输入”应停止本机流转，并保持关闭直至用户重新开启。挂死/断网测试记录实际耗时和目标按键状态，勿把核心进程结束等同于全部按键已释放。
