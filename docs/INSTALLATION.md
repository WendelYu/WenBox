# WenBox 安装、更新和流转设置

正式版：[GitHub Releases](https://github.com/WendelYu/WenBox/releases/latest)。请在两台电脑安装同一版本。M3 的文本同步需要两端都使用包含该功能的 1.4.8 测试包；1.4.7 正式版提供修饰键映射、鼠标/滚轮速度和按需文件分享。

## Windows

1. 下载 `WenBox-Windows-v版本号-Installer.exe`，退出正在运行的 WenBox 后执行安装。安装界面可选简体中文，允许选择安装目录。
2. 首次安装按提示确认管理员权限。输入服务随包安装；日常界面使用普通用户权限运行。选择本机受保护的 NTFS/ReFS 目录，例如 `C:\Program Files\WenBox` 或受保护磁盘根目录下的新文件夹。安装器会验证目录并保护服务文件。
3. 默认不内置、不自动下载 WebView2。已有 WebView2 的电脑可直接使用；提示缺失时，前往[微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)，选择 **Evergreen Standalone Installer → x64**。离线电脑可在其他电脑下载后复制安装，然后重新打开 WenBox。
4. 排查输入服务：CMD 执行 `sc query WenBoxKvm`；PowerShell 执行 `Get-Service WenBoxKvm`。运行状态应为 `RUNNING`/`Running`。服务启动与完成配对后输入连接成功是两个独立状态。

当前支持已登录桌面、管理员窗口和 UAC 安全桌面。首次安装和配对可临时接键鼠；完成后再验证拔掉目标键鼠的操作。保持 UAC 和安全桌面正常启用。

## Mac

1. 下载通用 DMG，打开后将 WenBox 拖到“应用程序”；ZIP 测试包解压后也放到“应用程序”。完全退出旧应用后再替换，确保只运行一个副本。
2. 在“键鼠流转 → 权限与连接详情”打开“辅助功能”和“输入监控”，添加 `/Applications/WenBox.app` 并开启。按页面提示重新打开应用。流转组件要求 macOS 14 或更新版本。
3. 当前没有 Developer ID 签名和 Apple 公证，更新后的临时签名可能使原授权失效。开关已开但输入仍失效时，在对应权限列表移除旧 WenBox，重新添加“应用程序”中的当前 WenBox。以应用权限页状态和诊断为准。

系统若阻止打开下载的测试应用，可在“系统设置 → 隐私与安全性”查看系统提供的允许打开入口。权限由用户在系统设置确认。

## 配对、布局、速度和按键

两端处于同一局域网并开启流转。主控选择“使用本机键鼠”，另一端选择“接收对端输入”；首次两端分别允许新设备配对，在一端选择另一台，核对相同的八位验证码并分别确认。后续保留设备授权，已开启且运行时自动连接。

在主控点击上下左右方向保存位置，光标越过对应边缘即可切换。指针和滚轮倍率独立调整；主控本机手感不受倍率设置影响。保存设置会短暂重连。

Mac 常用映射：Command→Ctrl、Control→Win、Option→Alt、Shift→Shift。可选择原始或自定义四个修饰键。M3 按对端分别保存自定义规则。左右同名修饰键共用规则，尚不支持任意普通键或宏。

Control+Alt+Escape 按主控原始按键返回本机。M3 增加“收回并停止输入”按钮，会停止流转，保留设备配对，需再次开启才能连接。

## M3 文本剪贴板

在两端“键鼠流转 → 文本剪贴板同步”分别开启。仅在已授权的输入连接就绪时工作；默认关闭。开启和重连时不覆盖已有剪贴板，从之后新复制的文本开始同步。

支持中文、多行文本和最多 1 MiB UTF-8 内容；超限在状态中提示，不会静默截断。图片和文件不通过该功能传输，复制的命令不会自动执行。关闭开关、停止流转、解除配对或断开连接会停止同步并丢弃待同步内容；重连后需新复制。

剪贴板内容只保存在内存中，经设备证书认证的加密通道传输，不写入日志或诊断，不经过房间 HTTP 接口。Windows 的系统剪贴板读写在普通桌面应用中进行，输入服务不读取 UAC 或登录界面的剪贴板。

## 房间文件

拖到房间文件区仅加入文件列表；拖到聊天区才发附件卡片。先发布名称和大小，收件人点击下载后才从发送方传输；发送方需保持当前页面/应用会话打开，重启后需要重新分享。房主转发新流程的数据时不保存副本。旧客户端的兼容上传接口会使用应用缓存。

房间、流转授权和文本同步是三个独立选择。加入房间不会自动获得键鼠控制权限，也不会自动开启剪贴板。

## M3.1 重启后的消息显示

本机聊天身份会持久保存，正常退出重开后，自己的新旧消息位置保持一致。旧版使用临时会话身份，已经丢失的旧记录不会仅凭昵称自动认领；确认是本机发送时，点击旧消息下方的“这是我发的”，该旧身份的历史消息会恢复到右侧。选错可点“撤销恢复”。此操作只调整本机显示，不修改消息内容或设备授权。
