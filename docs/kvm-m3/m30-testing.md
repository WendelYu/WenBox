# WenBox M3.0 测试版（应用版本 1.4.8）

v1.4.7 已正式发布：https://github.com/WendelYu/WenBox/releases/tag/v1.4.7
本目录为后续 M3 测试包。Mac、Windows 两端都更新后才可测试文本同步；原有配对保留。安装、WebView2 和 Mac 更新后权限恢复见仓库 docs/INSTALLATION.md。

## 文本同步

1. 两端打开 WenBox、开启流转，确认能跨屏输入。在两端“文本剪贴板同步”分别开启，等待就绪。
2. 开启后新复制中文、多行文本，在另一台记事本/文本编辑器粘贴；再换方向。已有剪贴板不会在开启或重连时自动覆盖另一端。
3. 大文本可在 Mac 终端执行 `python3 -c 'print("a"*1048576,end="")' | pbcopy`，确认 Windows 能粘贴完整文本。返程在 Windows PowerShell 执行 `Set-Clipboard -Value ('b' * 1048576)`，确认 Mac 能粘贴完整文本。
4. 复制超过 1 MiB 的文本时，流转页应提示超限，不应截断传输。关闭任一端同步开关、停止流转或断网后，新复制内容不应出现在对端；恢复后从新复制开始，不补发断开期间的内容。
5. 图片和文件不走此同步功能；仍可用房间文件按需分享。复制的命令只写剪贴板，不会自动执行。

## 映射和恢复

自定义修饰键规则现在按对端保存；保存后会短暂重连。检查 Command+A/C/V/Z 与原始/自定义模式。紧急停止按钮“收回并停止输入”保留配对并停止流转，需重新开启才会连接。

Mac 有独立的自有输入核心健康监测；Windows 目标挂死时的独立逐键释放尚未完成。100 ms 主动释放、2 s 故障恢复、真实 UAC 中断网及休眠恢复仍需单独真机验收。故障测试先保留可恢复的本地输入手段；正常使用仍支持 Windows 无实体键鼠。

## 构建和验证

Mac 源码 c460394，Windows 源码 9d2f6d1；Mac 额外修复健康监测的休眠计时，Windows 功能代码相同。
Mac 原生回归82通过/1忽略，Node47通过，Android33通过；浏览器工作区、文本开关、紧急停止、深浅色及窄屏检查通过。包括真实1MiB TLS传输和模拟IPC挂死回归，不等同于系统剪贴板/输入实际时延已达标。
