# M3.1 聊天位置修复（应用版本 1.4.8，诊断 m3.1）

修复旧版仅将发送者 ID 存入临时 sessionStorage，退出重开后历史消息被当作别人发送的问题。本机聊天身份和已确认的旧身份现在持久保存。

先更新出现问题的电脑即可；此修复不要求重新配对。Windows 使用本目录统一安装包覆盖安装；Mac 解压通用 ZIP 后替换“应用程序”中的 WenBox。Mac 更新后如输入权限失效，按安装说明重新添加当前应用的辅助功能和输入监控。

已经错位的旧记录：在确认是本机发送的同名旧消息下方点击“这是我发的”，该旧身份的历史消息会恢复到右侧。不同旧会话可能需要分别恢复。选错可点“撤销恢复”。只影响本机显示，不修改房间内容或控制授权。

验证：发一条新消息，完全退出再重开 WenBox，重新进入同一房间；自己的历史和新消息应保持右侧，同名其他设备仍应在左侧。恢复后的旧文件卡片链接保持原样；按需文件仍需要发送方在线，退出应用后需重新分享。

源码分支 codex/chat-reconnect-identity，提交 3a960a8。Node 51 项和完整浏览器回归已通过，覆盖清空会话后重开、重新入房、同名同IP设备区分、恢复/撤销、后续发送及文件链接。
