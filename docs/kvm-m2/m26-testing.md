# WenBox M2.6 测试版（应用版本 1.4.7）

Mac 和 Windows 均更新本目录测试包，房主也需要新版。Mac 解压后将 WenBox.app 放到“应用程序”，完全退出旧版后替换；不要同时运行两个副本。Windows 运行统一安装包，可选择中文和受保护的安装目录。安装包不含 WebView2，缺少时按安装器/应用指引下载。

## 按键映射

在主控的“键鼠流转 → 跨屏按键映射”中设置。Mac 默认“常用快捷键”：Command→Ctrl、Control→Win、Option→Alt、Shift→Shift。可选原始映射或自定义四个修饰键，四个目标不能重复，保存会短暂重连。左右同名修饰键共用映射；尚不支持任意普通键或宏重映射。

真机验证：跨到 Windows，在记事本输入文字，验证 Command+A/C/V/Z；切到原始映射确认 Control 快捷键；再修改一个自定义映射，重启 WenBox 确认保留。Mac 本机操作应保持原样。Control+Alt+Escape 按主控原始按键返回。

## 房间文件与聊天

拖到房间文件面板：仅加入房间列表，不自动发聊天消息。拖到聊天区或使用聊天附件：只发附件卡片。图片也使用待下载卡片，不自动取原图。

新分享仅发布文件信息，接收方点击下载并选择保存位置后才传输。传输经房主有界内存转发，房主不落地保存新流程的文件。旧版客户端上传兼容接口会写入应用缓存，不会写入公共下载目录。

发送方必须保持当前页面或 WenBox 会话打开；重启后需重新选择文件分享。退出房间、移除分享即撤销。离线检测约需 12 秒；浏览器后台被系统冻结时，也可能暂时显示离线，切回应用后重试。

真机验证：分享一个较大文件，在点击下载前确认接收端下载目录无新增文件；点击下载后对比大小和 SHA-256。关闭发送方再尝试，应该提示离线或失败，不应生成成功的空文件。两个接收者可分别请求同一个文件。

## Mac 权限

当前无 Developer ID，使用临时签名。更新后若跨屏输入失效，请在“辅助功能”和“输入监控”移除旧条目，重新添加 /Applications/WenBox.app，再重启应用。权限页可直接打开对应系统设置。
