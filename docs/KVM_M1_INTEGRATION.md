# KVM M1：已安装后端接入

日期：2026-10-27。状态：开发版代码；未发布，未完成集成后的双机真机验收。

## 决策依据

用户报告 Win11 在拔掉外接键鼠后光标正常，管理员窗口 Marker matched，并进一步确认 UAC 触发及操作正常。用户接受 Deskflow 的成熟实现，要求停止重复上游完整测试并开始开发。M0 核心可行性接受，完整 Win10、稳定性及性能矩阵不标为通过。

## 本轮实现

- 共享界面增加“流转”页；浏览器/Android 网页仅说明需使用桌面客户端，不调用原生控制接口。
- Tauri 原生命令：`kvm_status`、`kvm_start`、`kvm_stop`、`kvm_open_settings`，仅本机主窗口可信 Tauri 来源可用，不新增 HTTP 控制端点。
- 固定检测标准安装路径的 Deskflow 1.27.0，不允许前端传入可执行路径、启动参数、任意配置路径或 IPC 命令。
- macOS 直接管理已安装 `deskflow-core` 子进程，读取当前用户的标准配置并使用已保存角色、布局与证书信任。启动检查版本及安全配置，退出回收由本次 WenBox 启动的进程。
- Windows 使用固定 `deskflow-daemon` 命名管道恢复服务已有配置；只使用 hello/noop/start/stop，不提供 configFile 或任意命令接口。先停止 watchdog 再停止 core，避免正常停止后又被自动重启。已独立运行的会话只在用户点击停止时结束，退出不接管未由 WenBox 启动的会话。
- 版本受限的本地文本协议适配，响应限制 4KiB、读取总超时 800ms，支持分段响应；版本标记只用于兼容性检查，不是认证机制。Windows 使用非阻塞管道及 identification SQOS，避免无界阻塞与不必要的模拟权限。
- 只读检查 TLS/对端指纹验证和 Windows system 模式，禁止通过此入口启动配置中已启用的屏幕进入/离开命令功能。不自动写信任指纹，不把房间成员身份提升为控制授权。
- 显示本机角色、安全配置、后端运行、服务就绪及最近 50 条控制操作；不把运行状态误报为连接成功，不采集键盘内容。复制诊断包含上述状态及应用版本。
- 流转页可见时刷新，离开或切到后台即取消刷新；状态读取失败后清除旧的就绪状态，避免错误启动。

## 开发版怎么用

1. 保留 M0 已安装、已配置和配对的 Deskflow 1.27.0。Mac 放在 `/Applications` 或用户 `~/Applications`；Windows 使用标准 MSI 安装及后台服务模式。
2. Windows 后台服务需已从后端界面启动过一次，以保存标准配置路径；Mac 需已有正确角色、布局及权限。自定义路径/portable 本轮不支持。
3. 构建并启动新版 WenBox，进入“流转”。“打开后端设置”用于首次配置；“启动流转”复用配置，“停止流转”结束当前后端会话。若后端 GUI 自动启动已开启，它仍可能自行恢复会话；不要把 GUI 自动恢复误认为 WenBox 自己启动。
4. 提示未安装、配置编码不支持、服务未就绪或权限缺失时按提示处理。本轮不静默安装、不修改系统 UAC，不自动批准证书。
5. 仍需集成后的 Mac/Win11 双机启动/停止、应用退出和 UI 状态核对；当前只有上游 M0 真机结果，不把它替代集成验证。

## 验证

本机真实 Deskflow 的只读探测已成功识别已安装、正在运行、主控角色及加密配置；没有启动/停止或修改用户会话。发现真实 IPC 握手为 `1.27.0.0+081f6478`（CLI 显示 v1.27.0），已加入固定版本兼容检查与回归。

已执行结果记录在 progress.md：Rust 回归、Node 回归、新增原生桥模拟 UI、完整共享 Web 浏览器流程、Windows 平台适配器类型检查。Windows 检查通过临时最小 crate 编译完整后端管理代码（排除 Tauri 宏桥），不等于已生成/运行 Windows 安装包。

新增测试覆盖错误版本阻断、超长/断开的响应、分段/超时 IPC、安全开关与配置编码、远端页面/次窗口访问限制、挂起子进程版本检测回收、前端状态失败及轮询清理。浏览器原生桥测试完全模拟，不连接真实输入服务。

全量 CSS lint 存在原有 polish.css/workspace.css 的 8 个错误和 18 个警告；新增 kvm.css 单独 lint 通过。本轮未修改这些既有样式问题。

## 仍未实现

- WenBox 内设备身份/验证码配对、授权撤销、房间成员映射、布局编辑与自动重连协调（M2）。
- 单一安装包及 Windows 特权服务的安装/升级/卸载；当前需保留单独安装的 Deskflow。未向正式包加入上游二进制，也未更改项目 MIT 声明。
- 生产集成前仍需评估现成高权限服务的本地 IPC 访问面、配置文件权限与签名，不把此版本的 WorldAccess IPC 当成经过设备认证的安全边界。
- 紧急释放全局热键、双端 2 秒失联释放、输入状态清理及完整进程故障恢复（M3）；当前提供的是停止后端会话，不能等同于这些保证。
- macOS 12.3 兼容构建（官方 arm64 1.27.0 包要求 14.0）、安装包增量 ≤8MB、Intel Mac 和 Win10 集成验收。
- WenBox 管理的文本剪贴板（P1 必做）；当前既有后端的剪贴板开关仍由后端设置控制。
