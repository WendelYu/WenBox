# WenBox 工程师与工控百宝箱 (by Wendel)

> 专为**现场调试、工程师日常开发、发票报销整理、上位机测试与多端协同**量身定制的轻量全能工具箱。
> 支持 **Android 手机端** 与 **Windows / macOS 桌面端 (Rust / Tauri 超轻量单文件)**，支持零安装的纯 Web 浏览器访问。

---

## 🌟 核心特性与功能模块

### 1. 🌐 局域网去中心化对等互联 (P2P 双向服务端)
- **多端皆为服务端**：
  - **Android 手机端**：内置极简高并发 HTTP 服务（端口 `9527`）。
  - **Windows 桌面端**：基于 **Rust (Tauri)** 内嵌极轻量 HTTP 服务（端口 `9527`），开箱即用，内存仅占 20~30MB。
  - **浏览器直接访问**：局域网内任意未装客户端的电脑/手机，直接在浏览器打开 `http://[设备IP]:9527` 即可无缝加入。
- **UDP 局域网节点自发现 (端口 9528)**：
  - 所有设备开机后自动宣告与探测局域网内的 WenBox 节点。
  - 动态展示在线设备的 **设备名称、IP 标识、平台图标 (📱/💻)**，自动剔除离线节点。
- **按需下载**：
  - 随时切换查看任意在线设备的文件列表，点击**【按需下载】**精准拉取所需文件，支持电脑向手机反向拖拽投送。

---

### 2. 📁 灵活的日期归档直存模式 (报销/照片/发票/日志整理利器)
- **免压缩包、零解压**：彻底告别 ZIP 压缩包与反复解压的繁琐流程，基于现代浏览器标准 File System Access API。
- **自定义归类主题**：
  - 在电脑端指定存放总根目录，可自由输入文件夹后缀（默认 `报销`，可自由自定义为 `发票`、`现场照片`、`工控日志` 或留空）。
  - 程序自动在所选根目录下创建当天格式的子文件夹（例如 `2026-09-21_报销/` 或 `2026-09-21_现场照片/`）。
  - 手机或对应设备上传的所有发票/图片/文件直接整齐存入该日期目录下，一步到位。

---

### 3. 💬 局域网即时多端聊天室 (去中心化双向互通)
- **毫秒级同步**：任何设备发送文字、网址链接、代码片段、剪贴板内容，局域网聊天室实时同步。
- **设备身份与便捷操作**：
  - 消息自动标注设备来源（如 `💻 Windows端`、`💻 Mac端`、`📱 手机端`）。
  - 每一条消息支持点击一键复制到剪贴板，支持一键清屏与换行输入 (`Ctrl + Enter` 发送)。

---

### 4. 📋 JSON 格式化与校验工具箱 (双端同享)
- **手机 App + 电脑桌面 / Web 端全覆盖**：
  - **分级美化**：支持 2 空格 / 4 空格层级美化排版。
  - **单行精简**：一键剔除多余空白与换行，适合复制到协议报文或接口中。
  - **语法定位**：格式有误时精准提示语法报错原因。
  - **快捷操作**：支持内置丰富模板加载、一键全选复制与清空。

---

### 5. ⚙️ 多进制实时互转 (HEX / DEC / BIN / OCT / ASCII)
- **秒级多向联动**：在 16 进制 (HEX)、10 进制 (DEC)、2 进制 (BIN)、8 进制 (OCT)、ASCII 文本任意框内输入，其余进制秒级自动联动换算。
- **优雅排版**：HEX 自动按两两字节分组（如 `1A 3F`），BIN 自动按 4 位分组，支持单独一键复制各进制结果。

---

### 6. ⏱️ Cron 表达式工作台
- **秒级模板覆盖**：支持包含 `* * * * * ?` 在内的秒级、分钟级、工作日等常见模板一键套用。
- **中文大白话反解**：自然语言实时反解 Cron 语义（如“每秒执行一次”、“工作日(周一至周五) 09点00分 执行”）。
- **未来时刻预演**：精准推演并列出接下来的 **5 次预计触发时刻**（精确到秒）。

---

## 📦 下载与自动发布 (Releases)

本项目配置了完整的 **GitHub Actions CI/CD** 全自动多平台流水线：

每次提交版本标签（如 `v1.0.0`），云端将全自动交叉编译并发布到 [GitHub Releases](https://github.com/WendelYu/WenBox/releases)：

| 平台 | 格式 | 特性 |
| :--- | :--- | :--- |
| **Android** | `.apk` | 支持 Android 8.0+，纯局域网免流量直传，前台服务稳定保活 |
| **Windows** | `.exe` (单文件) | **Rust / Tauri 编译**，仅 **3~5 MB** 超轻量，低内存占用，内置 HTTP 服务 |
| **Windows** | `.exe` (安装包) | 带安装向导的标准安装程序 |
| **任意设备** | Web 页面 | 电脑/平板浏览器直接访问 `http://[设备IP]:9527` 即可使用全部功能 |

## 🛠️ 本地编译构建指引

### 1. Android 端编译
- 使用 **Android Studio** 打开工程根目录。
- 菜单栏点击 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**。
- 产物路径：`app/build/outputs/apk/debug/app-debug.apk`。

### 2. Windows / 桌面端编译 (Rust / Tauri)
- 前置依赖：安装 [Rust](https://rustup.rs/) 与 [Node.js](https://nodejs.org/)。
- 编译命令：
  ```bash
  npm install
  npx @tauri-apps/cli build
  ```
- 产物路径：`src-tauri/target/release/wenbox.exe`。
