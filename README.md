# WenBox 局域网跨设备互传与全能多端工具箱 (by Wendel)

> 专注于**局域网跨平台高速文件双向互传、即时通讯与实用开发辅助**的轻量全能百宝箱。  
> 支持 **Android 手机端**、**Windows 桌面端 (Rust / Tauri 超轻量单文件)** 以及零安装的纯 Web 浏览器访问。

---

## 🌟 核心特性与功能模块

### 1. 🏠 创新房间制局域网传输架构 (默认客户端发现，建房即主机)
- **默认客户端发现大厅 (Client Discovery Mode)**：
  - 软件在 Windows 桌面端或手机 App 启动时，**默认均为客户端模式**，纯粹监听局域网房间，不占用服务端口、不无故广播干扰网络。
  - 后台自动监听 UDP `9528` 端口，秒级自动发现局域网内其他设备创建的房间，直观展示房间名称、房主设备、IP 端口及密码状态。
- **一键建房变身服务端 (Host Mode)**：
  - 点击**【➕ 创建房间】**即可变身服务端，自由设定房间名称与入房 PIN 码（支持留空免密）。
  - 创建后本机**动态激活为服务端主机 (Port 9527)**，并向局域网广播自身房间。
  - 主机控制台提供直观的**【📱 扫码秒进】二维码**、**【📋 复制入房直链】**、**【👥 实时在线成员与访问 IP】**与安全**【⏹️ 解散房间】**确认功能。
- **自定义入房昵称与 IP 追溯**：
  - 加入房间时支持手动输入个性化昵称（如 `我的笔记本`、`小明手机`）。
  - 房间内所有成员统一以 **`昵称 (IP)`** 格式清晰展示，谁在线、谁发的消息一目了然。
- **双向互传与局域网满速**：
  - 双方进入房间后即建立端到端直连：客户端可浏览并下载房主分享的文件，也可将手机/电脑端文件直接推送到对方电脑的 `Downloads/WenBox/` 目录。
  - 摒弃了 WebRTC 常见的 NAT 穿透失败与内存溢出瓶颈，采用局域网原生流式 HTTP 传输，轻松跑满千兆 Wi-Fi (100MB/s+)。

---

### 2. 💬 局域网即时通讯与聊天室 (支持富文本、截图与文件)
- **实时互发消息**：手机与电脑处于同网络进入房间后，文本、链接、代码段与剪贴板秒级互通。
- **在线人数与访问 IP 状态栏**：
  - 聊天室顶部清晰展示当前**实时在线人数**（如 `👥 在线: 2 人`）与**房间访问地址**（如 `🌐 访问: http://192.168.1.100:9527`），支持一键复制链接分享。
- **丰富消息格式与快捷操作**：
  - 支持 **Ctrl+V 粘贴截图** 直接发送图片，支持拖拽文件发送。
  - 消息自动标注发送设备与 `昵称 (IP)`，提供一键复制与清屏功能。
- **断开与解散自愈**：
  - 房主解散房间时，全网广播通知，客户端平滑断开并自动返回大厅，避免程序卡死或崩溃。

---

### 3. 📁 灵活的日期归档直存模式 (照片/文档/报销整理利器)
- **免压缩包、零解压**：基于现代浏览器标准 File System Access API，无需打包与反复解压。
- **自定义归类主题**：
  - 在电脑端指定存放总根目录，可自由输入文件夹后缀（默认 `报销`，可自由自定义为 `发票`、`现场照片`、`文档归档` 或留空）。
  - 程序自动在所选根目录下创建当天格式的子文件夹（例如 `2026-09-21_现场照片/`）。
  - 上传的文件直接整齐存入该日期目录下，一步到位。

---

### 4. 📋 JSON 格式化与校验工具箱 (双端同享)
- **分级美化**：支持 2 空格 / 4 空格层级美化排版与语法错误精准定位。
- **单行精简**：一键剔除多余空白与换行，适合复制到报文或接口中。
- **模板与快捷操作**：内置丰富示例模板，支持一键全选复制与清空。

---

### 5. ⚙️ 多进制实时互转 (HEX / DEC / BIN / OCT / ASCII)
- **秒级多向联动**：在 16 进制 (HEX)、10 进制 (DEC)、2 进制 (BIN)、8 进制 (OCT)、ASCII 文本任意框内输入，其余进制秒级自动联动换算。
- **优雅排版**：HEX 自动按两两字节分组（如 `1A 3F`），BIN 自动按 4 位分组，支持单独一键复制各进制结果。

---

### 6. ⏱️ Cron 表达式工作台
- **模板丰富**：支持常用秒级、分钟级、工作日等常见模板一键套用。
- **大白话反解**：自然语言实时反解 Cron 语义（如“每秒执行一次”、“工作日 09点00分 执行”）。
- **未来时刻推演**：精准推演并列出接下来的 **5 次预计触发时刻**（精确到秒）。

## 📦 下载与自动发布 (Releases)

本项目配置了完整的 **GitHub Actions CI/CD** 全自动多平台流水线：

每次提交版本标签（如 `v1.1.0`），云端将全自动交叉编译并发布到 [GitHub Releases](https://github.com/WendelYu/WenBox/releases)：

| 平台 | 格式 | 特性 |
| :--- | :--- | :--- |
| **Android** | `.apk` | 支持 Android 8.0+，纯局域网免流量直传，前台服务稳定保活 |
| **Windows** | `.exe` (单文件) | **Rust / Tauri 编译**，仅 **3~5 MB** 超轻量，低内存占用，内置 HTTP 服务 |
| **Windows** | `.exe` (安装包) | 带安装向导的标准安装程序 |
| **任意设备** | Web 页面 | 手机/平板/电脑浏览器直接访问 `http://[设备IP]:9527` 即可使用全部功能 |

## 🛠️ 本地编译构建指引

### 1. Android 端编译
- 使用 **Android Studio** 打开工程根目录。
- 菜单栏点击 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**。
- 产物路径：`app/build/outputs/apk/debug/app-debug.apk`。

### 2. Windows / 桌面端编译 (Rust / Tauri)
- 前置依赖：安装 [Rust](https://rustup.rs/) 与 [Node.js](https://nodejs.org/)。
- 编译命令：
  ```bash
  npm install
  npx @tauri-apps/cli build
  ```
- 产物路径：`src-tauri/target/release/wenbox.exe`。
