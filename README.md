# WenBox 工程师与工控百宝箱 (by Wendel)

专为**现场调试、工程师日常开发、报销文件互传、上位机与测试**量身定制的轻量全能工具箱 Android 应用。手机端与电脑端（浏览器 9527 端口）双向无缝联动。

---

## 🌟 核心功能模块

### 1. 📁 局域网极速互传 & 🧾 报销直存模式 (Win / Mac 兼容)
- **电脑端零安装**：手机启动服务后，电脑浏览器直接打开网址（默认端口 `9527`）即可极速下载手机文件，支持将电脑文件拖拽上传回手机。
- **🧾 报销直存模式 (无 ZIP，一键直达)**：
  - 针对财务报销发票（PDF、图片等）整理痛点，采用现代浏览器标准文件系统接口（File System Access API）。
  - 在电脑端只需选定报销总根目录（如 Windows `D:\报销` 或 Mac `~/报销`），系统**自动根据当天日期建立子文件夹**（例如 `2026-09-21_报销`），并将所有手机上传的发票直接写入该目录。
  - **绝不打包 ZIP**，零解压步骤，一步到位！
- **全网络接口识别**：智能捕获 **有线网卡 (eth0)**、**手机个人热点 (SoftAP 192.168.43.1)**、**Wi-Fi 局域网** 与 **USB 共享**，动态抓取系统真实 IP，并生成二维码联动。
- **免流量直传**：手机开热点直连时属于纯局域网高速传输，**完全不消耗手机任何蜂窝移动流量**。

### 2. 💬 局域网即时互发消息 / 聊天室
- **自动握手互联**：只要电脑（Windows/Mac）与手机处于同一 Wi-Fi 或连接手机热点，打开网页自动加入局域网聊天室。
- **双向极速互发**：
  - 电脑向手机发送长文本、链接、代码段、剪贴板；手机 App 即时接收并呈现气泡。
  - 手机端直接输入发送，电脑网页毫秒级同步显示。
  - 消息点击一键复制，自带清屏与设备身份标识（`💻 Windows端` / `💻 Mac端` / `📱 手机端`）。

### 3. 📋 JSON 格式化与校验工具箱 (双端同享)
- **手机 App + 电脑 Web 端全覆盖**：
  - **美化排版**：支持 2 空格 / 4 空格层级美化。
  - **单行压缩**：一键精简为单行去除空白，适合复制到报文或请求体。
  - **语法校验**：精确定位 JSON 格式语法报错原因。
  - **快捷操作**：支持内置丰富示例加载、一键全选复制、一键清空。

### 4. ⚙️ 多进制实时互转 (HEX / DEC / BIN / OCT / ASCII)
- **极简联动**：在 16 进制 (HEX)、10 进制 (DEC)、2 进制 (BIN)、8 进制 (OCT)、ASCII 字符任意一个输入框中输入，其余进制秒级联动同步换算。
- **贴心格式化**：HEX 自动按两两字节空开（如 `1A 3F`），BIN 自动按 4 位分组，一键点击复制各个进制结果。

### 5. ⏱️ Cron 表达式工作台
- **秒级模板支持**：支持以 `* * * * * ?` 为首的秒级、分钟级、工作日等常用预设模板一键套用。
- **中文大白话反解**：自然语言解析 Cron 含义（如“每秒执行一次”、“工作日(周一至周五) 09点00分 执行”）。
- **未来时刻预演**：精准推演并列出接下来的 **5 次预计触发时刻**（精确到秒）。
